Notes & troubleshooting

  1. If you already enabled GitHub Pages in repository settings and the site doesn't appear, wait a few minutes for GitHub to build and publish.
  2. If the Pages source is set to a branch/folder other than main / (root), either change it in Settings → Pages or move this index.html into the configured folder (for example: docs/index.html).
  3. If you prefer a fully generated static site (instead of linking raw markdown), I can add a GitHub Action to build and deploy a site automatically — tell me if you want that.
